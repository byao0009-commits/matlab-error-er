# matlab-error-er
发一张 MATLAB 或 Simulink 报错截图，就知道命令在哪输、哪行代码要改、结果怎么验。面向中国高校实验课，按你的 MATLAB 版本给出可复制的修复命令。  Turn a MATLAB or Simulink error screenshot into copy-ready commands, targeted code edits, and a quick way to verify the fix. Built for Chinese university labs, with fixes tailored to your MATLAB version.
